# Calculadora VT8

Aplicación Java sencilla que permite realizar operaciones matemáticas, por ahora solo permite sumar.
No le pidas nada más por ahora!!!!!!

## Diseño

Main --> Calculadora

- Main inicia la aplicación.
- Calculadora contiene las operaciones matemáticas.

## Criterio de validación

Si se llama a sumar(5, 5), el resultado debe ser 10.
